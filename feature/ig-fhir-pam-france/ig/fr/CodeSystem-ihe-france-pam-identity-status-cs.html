CodeSystem: IHE France PAM Identity Status CodeSystem

URL officielle: https://hl7.fr/ig/v2/pam/CodeSystem/ihe-france-pam-identity-status-cs Version: 0.1.0
Draft à date du 2026-10-20 Nom computable: IHEFrancePamIdentityStatusCS

Statuts et attributs de l’identité du patient (PID-32, table HL7 0445 spécialisée pour la France).

Ce système de codes est référencé dans la définition des ensembles de valeurs suivants :

  • IHE France PAM Identity Status ValueSet

This case-sensitive code system https://hl7.fr/ig/v2/pam/CodeSystem/ihe-france-pam-identity-status-cs defines the following codes:
