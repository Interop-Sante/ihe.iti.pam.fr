Extension: IHE France PAM Accident Nature

URL officielle: https://hl7.fr/ig/v2/pam/StructureDefinition/ihe-france-pam-accident-nature Version: 0.1.0
Draft à date du 2026-10-28 Nom computable: IHEFrancePamAccidentNature

Nature de l’accident (ACC-2). Le segment ACC est obligatoire lorsque l’entrée du patient fait suite à un accident.

Context of Use

    Cette extension peut être utilisée sur les éléments suivants

    • ID d'élément: Encounter
